About Hash Algorithms

MD5 — 128-bit hash. Fast but cryptographically broken. Use for checksums, not security.

SHA-1 — 160-bit hash. Deprecated for security, but still used in Git and legacy systems.

SHA-256 — 256-bit hash. Part of the SHA-2 family. Industry standard for TLS, certificates, blockchain.

SHA-384 — 384-bit hash. Truncated SHA-512 variant. Used in higher-security contexts.

SHA-512 — 512-bit hash. Strongest in the SHA-2 family. Slower but more resistant to collision attacks.

MD5 is implemented in pure JavaScript. SHA hashes use the Web Crypto API (SubtleCrypto).
