About Base64

Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format. It's commonly used for:

  • Embedding images (data URIs) in HTML/CSS
  • Encoding email attachments (MIME)
  • Storing binary data in JSON or databases
  • Authentication headers (Basic Auth)

This tool uses the standard Base64 alphabet with + and / characters and = padding.
