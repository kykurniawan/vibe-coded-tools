🔗 URL Encoder / Decoder

Encode or decode URL components and full URLs. Handles special characters and Unicode.

Difference between URI and Component encoding

encodeURI encodes the full URI but preserves characters that are valid in a URI (:/?#[]@!$&'()*+,;=-._~).

encodeURIComponent encodes everything, making it safe for embedding in query string values.
