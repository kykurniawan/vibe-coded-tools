🔑 JWT Decoder

Decode JWT tokens without sending them to a server. Inspect header, payload, and signature parts.

About JWT

A JWT (JSON Web Token) has three base64url-encoded parts separated by dots: header.payload.signature. This tool decodes the header and payload only — it does NOT verify the signature. No data is sent anywhere.
