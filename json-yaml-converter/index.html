🔄 JSON ↔ YAML Converter

Convert between JSON and YAML in both directions with live validation and line-accurate syntax errors. 100% client-side — your data never leaves the browser.

⚠️ Notes: Uses the js-yaml library (v4, YAML 1.2 core schema) — same approach as the QR tool's library. YAML anchors, aliases, and complex tags are expanded to plain values. Duplicate keys in YAML are reported as errors. Both panes are plain text; nothing is uploaded anywhere.
