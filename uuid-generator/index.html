🆔 UUID Generator

Generate UUID v4 (random) and UUID v7 (time-ordered) identifiers. All generated client-side using crypto.randomUUID().

About UUID Versions
UUID v4 — Random UUID. All bits except the version (4) and variant (10xx) are randomly generated. 122 bits of entropy. Best for general-purpose use where uniqueness is the only requirement.
UUID v7 — Time-ordered UUID. 48 bits of Unix timestamp (ms precision) followed by random data. Monotonically increasing, sortable, database-index-friendly. Draft standard (RFC 9562).
